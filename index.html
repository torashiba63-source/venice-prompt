顔固定・構図転写プロンプト

1枚目の顔を保ったまま2枚目の構図にするための英語プロンプトを作ります。コピーして Venice の画像編集に貼ってください。

1枚目 = 顔毎回同じ写真。前回の出力を1枚目にしない。
2枚目 = 構図顔が小さい・伏せた画像が安全。

条件

選ぶと下のプロンプトが自動で変わります。

0 / 1500
Venice での手順
  1. 画像編集を開く
  2. 1枚目に顔写真、2枚目に構図をこの順で添付
  3. プロンプトを貼る
  4. アスペクト比を2枚目と同じに設定
  5. 生成。崩れたら項目を1つだけ変えて再試行
1500文字を超えています。短縮モードか項目数で調整してください。
崩れたときの調整
  • 顔が別人化 → 顔の可視性を強め、アナトミーを「弱め」に
  • 局部が溶ける → アナトミーを「強め」に。顔と同時に上げない
  • 体が細くなる → 体つきを明示、腰・顎を細くしないを残す
  • 2枚目の顔が混ざる → 2枚目を顔が小さい・伏せた画像に差し替える
  • 手指が崩れる → 手を画面外に落とすポーズにする
  • 全身で顔が読めない → アスペクト比を 2:3 か 3:4 の縦にする
